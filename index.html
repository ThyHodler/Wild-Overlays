Guía rápida de tipos de escena

Escenas Imprescindibles
Starting Soon / Pre-stream
Objetivo: Mostrar contenido mientras te preparas antes de darle a "Iniciar transmisión". Función: Música de espera, logo animado, hora de inicio prevista, redes sociales. Evita que la gente vea tu escritorio desordenado.
Live / Juego en pantalla
Objetivo: Tu escena principal de contenido. Función: Captura del juego + overlay con cámara, chat, alertas, HUD. Es la escena por defecto al estar on-air.
BRB / Pausa corta
Objetivo: Cubrir ausencias imprevistas de 1 a 5 minutos. Función: "Vuelvo en breve", con música loop. Para ir al baño, atender algo urgente.
Break / Intermedio
Objetivo: Pausas programadas más largas. Función: "Regreso en 10 min", cuenta regresiva, highlights. Se usa entre juegos o bloques de contenido.
Just Chatting / Sin juego
Objetivo: Conversar con la audiencia sin gameplay. Función: Cámara grande, fondo, chat visible. Ideal para charlas, Q&A, anuncios.
Fin de Stream / Goodbye
Objetivo: Cierre profesional. Función: Agradecimiento, resumen del stream, redes sociales y próximo horario. Puedes dejarla unos minutos tras detener la transmisión.
Transición / Stinger
Objetivo: Dar profesionalismo al cambiar de escena. Función: Animación corta de 0.5-2s entre escenas. No es una escena fija, pero es imprescindible.
Escenas Específicas y Avanzadas
Cambio de Juego / Intermisión
Objetivo: Mantener retención mientras cargas otro juego. Función: Pantalla con "Cambiando de juego...", música, y mensajes de chat activado.
Invitado / Duo Stream
Objetivo: Adaptar el layout cuando hay más de una persona. Función: Dos cámaras, dos nombres, más espacio para chat. Variantes: invitado izq/der, cámara grande/pequeña.
React / Reacción a contenido
Objetivo: Reproducir video externo y reaccionar. Función: Layout con tu cámara en picture-in-picture y ventana de video al 70-80% de pantalla. Perfecto para YouTube, TikTok, clips.
React con Invitado
Objetivo: Reacción en conjunto. Función: Similar a React pero con 2 cámaras + video. Se suele usar cámara pequeña para cada uno y video grande centrado.
Screen Share / Presentación
Objetivo: Mostrar pantalla para tutoriales, Discord, diseño, etc. Función: Captura de pantalla limpia sin juego, con cámara pequeña y anotaciones.
Cámara Off / Audio Only
Objetivo: Seguir el stream sin mostrarte. Función: Solo juego + overlay + mensaje "Cámara apagada por X motivo". Útil por privacidad o problemas de luz.
Technical Difficulties
Objetivo: Problemas técnicos graves. Función: Pantalla estática con "Problemas técnicos, regresamos pronto". Evita que se vea el BSOD o el escritorio.
Giveaway / Sorteo y Polls
Objetivo: Interacción activa con la comunidad. Función: Diseño limpio con espacio para leer nombres, overlay de Streamlabs, y contador.
Cámara Principal / IRL
Objetivo: Streams sin PC, solo charla. Función: Cámara grande, fondo, micrófono destacado. Ideal para Just Chatting IRL.
Espera de Invitado
Objetivo: Mientras el invitado se conecta. Función: Similar a Starting Soon pero con texto "Esperando a [Nombre]...".
