# Wild-Overlays
# 🎬 StreamPrompt Engine

**Generador de prompts para crear overlays de stream con IA.**
Elige el tipo de recurso, el estilo, los colores y la plataforma, y la herramienta te arma un prompt completo y listo para pegarlo en tu asistente de IA favorito (Claude, ChatGPT, Gemini, etc.). La IA te devuelve el código del overlay, la alerta o la pantalla.

Hecho por **Nicothewild** · WILD Overlays

## 💾 Descargar y usar sin internet de GitHub

1. Descarga `index.html` (botón **Download raw file** o **Code → Download ZIP**).
2. Ábrelo con tu navegador (Chrome, Edge, Firefox).
3. Listo. No necesitas instalar nada.

> La herramienta carga Tailwind, los iconos y las fuentes desde internet, así que necesitas conexión la primera vez que la abres.

## 🧩 Cómo funciona

1. **Configura los 5 campos clave**
   - **Tipo de recurso:** pantalla de inicio, "volvemos pronto", fin de stream, alertas (seguidor, suscriptor, donación, raid, miembro, bits), widget de chat, marco de webcam, barra de progreso, overlay de gameplay o de Just Chatting.
   - **Estilo visual:** Cyberpunk, Futurista, Sci-Fi, Minimalista, Esports, Pixel Art, Neon Retro Gaming, Glassmorphism y más.
   - **Descripción del recurso:** estándar, UI/UX Pro o personalizada.
   - **Comportamiento:** visible siempre, oculto, con animación, con temporizador, activable por JavaScript, reutilizable sin recargar, etc.
   - **Plataforma de destino:** StreamElements, Streamlabs, OBS, Meld Studio, Streamer.bot o una personalizada.
2. **Agrega los datos del streamer:** nombre del canal, eslogan, redes sociales, resolución (1080p, 2K, 4K o vertical 9:16) y la librería que prefieras (Vanilla JS, GSAP, Alpine.js, Vue 3 o que la IA decida).
3. **Elige tu paleta de colores:** presets profesionales, palabras clave de color o hasta 3 colores hex (principal, secundario y acento).
4. **Copia el prompt generado** con el botón **Copiar Prompt** y pégalo en tu IA.
5. **Pega el código resultante** en tu plataforma (fuente de navegador en OBS, widget personalizado en StreamElements, etc.).

Cada campo tiene la opción **✏️ Campo Personalizado** por si lo que necesitas no está en la lista, y el botón **Reiniciar Campos** deja todo en blanco.

## 📚 Guía de escenas incluida

La herramienta trae una guía rápida con el objetivo y la función de cada escena que necesita un stream:

- **Imprescindibles:** Starting Soon, Live, BRB, Break, Just Chatting, Fin de Stream, Transición/Stinger.
- **Avanzadas:** Cambio de juego, Invitado/Duo, React, React con invitado, Screen Share, Cámara Off, Technical Difficulties, Giveaway/Polls, IRL y Espera de invitado.
